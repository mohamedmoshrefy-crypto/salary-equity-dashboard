# Executive Salary Equity & Compa-Ratio Analysis

## Overview
This project demonstrates an end-to-end Compensation & Benefits (C&B) analysis evaluating salary distribution, gender pay gaps, and Compa-Ratios across departments and seniority levels.

> **Note:** Dataset is synthetic and created for portfolio demonstration purposes.

## Key Metrics & Analytics
* **Compa-Ratio Distribution:** Analysis of market positioning by department.
* **Gender Pay Gap Analysis:** Evaluation of base salary parity across job levels.
* **Flight Risk Correlation:** Cross-referencing pay equity with employee tenure and performance ratings.

## Tech Stack
* **Tools:** Power BI / Advanced Excel
* **Data Format:** CSV / Data Modeling (DAX)
